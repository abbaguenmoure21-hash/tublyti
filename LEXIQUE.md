# LEXIQUE.md — Mots affichés dans TubLyTI

Ce fichier fait autorité pour tous les textes visibles par l'utilisateur (app, landing, e-mails, extension). Les noms techniques restent dans le code et la base de données, mais **ne s'affichent jamais**.

## Règles

1. Des mots simples, sans jargon. Si un terme a besoin d'une explication, il doit être dans la page Guide.
2. Ne jamais utiliser « tourner » pour parler de créer une vidéo : dire « créer », « publier » ou « choisir un sujet ».
3. Les titres de page sont la question à laquelle l'écran répond.
4. Les boutons commencent par un verbe : « Valider ce sujet », « Ajouter une chaîne ».
5. Tutoiement partout, typographie française (espace avant « : ? ! », guillemets « »).
